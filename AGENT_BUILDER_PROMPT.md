## 2. ЧТО НУЖНО ПОСТРОИТЬ

Новый ядро приглашения и два редактора + визуальная рассадка. Всё типобезопасно, на TypeScript, на React, без сторонних проприетарных page-builder библиотек. Делай сам, не тащи 500кб зависимости типа craft.js/grapesjs если можно сделать проще и легче.

### 2.1. Ядро: документ-приглашение (Canvas Document)
Определи строгий TS-интерфейс `InvitationCanvasDocument` и отдельные типы для каждого элемента:
```ts
// src/lib/canvas/types.ts
export interface InvitationCanvasDocument {
  version: 1;
  width: number; // дизайн-ширина (390 = mobile, 1200 = desktop), mobile-first
  background: CanvasBackground;
  elements: CanvasElement[];
  mobile: InvitationCanvasDocument; // отдельная раскладка для мобильного (автогенерится, но можно править)
}

export type CanvasElement =
  | TextElement
  | ImageElement
  | ButtonElement
  | ShapeElement
  | RsvpFormElement
  | CountdownElement
  | CoupleNamesElement
  | WishesElement
  | ProgramElement
  | MapElement
  | LottieElement
  | DividerElement
  | VideoBgElement;

export interface BaseElement {
  id: string; // nanoid
  type: CanvasElement['type'];
  x: number; // в процентах от ширины (0-100)
  y: number; // в пикселях от верха
  w: number; // в процентах ширины
  h: number; // в пикселях или 'auto'
  rotation: number;
  zIndex: number;
  locked: boolean;
  hidden: boolean;
  animation?: AnimationConfig;
  mobile?: Partial<BaseElement>; // оверрайд для мобильной версии
  responsive?: { preserveAspect?: boolean; hideOnMobile?: boolean; hideOnDesktop?: boolean };
}

export interface AnimationConfig {
  type: 'none' | 'fade' | 'fadeUp' | 'fadeDown' | 'zoomIn' | 'slideLeft' | 'slideRight' | 'flip';
  duration: number;
  delay: number;
  easing: 'ease' | 'ease-in' | 'ease-out' | 'ease-in-out';
  once: boolean; // проиграть 1 раз при появлении в вьюпорте
}
```

- Все координаты в процентах по ширине для адаптива, вертикаль в пикселях (страницы скроллятся вертикально, там абсолютные координаты ок).
- Элементы строго типизированы, не `any`, не `Record<string, any>`.
- Сохранение документа в БД: в таблице `Invitation` добавь поле `canvas: Json?` и `mobileCanvas: Json?`, старые поля templateData и т.п. не удаляй — используй для обратной совместимости/конвертации.
- Сделай валидацию через zod: `canvasDocumentSchema`, отклоняй любые невалидные документы на входе в API.

### 2.2. Продвинутый редактор (Canvas Editor / Page Builder)
Режим как у shaqyru24:
- Весь предпросмотр приглашения — это абсолютный холст с масштабом 1:1 в десктопе, адаптив-переключатель "мобильный/десктопный вид".
- **Клик на элемент** = синяя рамка-выделение, маркеры ресайза по углам, маркер вращения.
- **Перетаскивание мышом/пальцем** меняет x/y в реальном времени, плавно, без лагов.
- **Ресайз за углы** меняет w/h, с сохранением пропорций по Shift.
- **Вращение** за круглый маркер над выделенным элементом.
- **Правая панель свойств (Inspector)**: контекстно меняет контролы в зависимости от выбранного типа элемента:
  - Текст: контент, гарнитура, размер, насыщенность, цвет, выравнивание, межстрочное, буквенный интервал, тень текста.
  - Изображение: скругление, обводка, тень, оверлей-цвет, фит (cover/contain), alt-текст, клик-ссылка.
  - Кнопка: текст, цвет фона, цвет текста, скругление, тень, ссылка/действие (на РСВП, на карту, на телефон).
  - Фигура: форма (прямоугольник/круг/линия), заливка, обводка, прозрачность.
  - Общее для всех: позиция вручную (x/y/w/h числами), угол поворота, z-index (выше/ниже), блокировка, скрытие, удалить, дублировать.
- **Левая палитра компонентов**: разделы "Текст", "Фото", "Кнопки", "Счётчик", "Форма РСВП", "Пожелания", "Таймер", "Карта", "Программа", "Декор", "Видео фон". Перетаскивание элемента с палитры на холст = создание в точке дропа.
- **Топ-тулбар**: undo/redo (обязательно! на каждую операцию в истории), зум (100/75/50% / fit), переключение мобильный/десктоп, сетка вкл/выкл, направляющие выравнивания (когда два элемента выравниваются по краю/центру — линия-подсказка с прилипанием), "вернуться к быстрому редактированию", "предпросмотр для гостей".
- Горячие клавиши: Ctrl+Z отмена, Ctrl+Shift+Z возврат, Delete удалить, Ctrl+D дублировать, стрелки подвинуть на 1px, Shift+стрелки на 10px, Ctrl+C/Ctrl+V.
- **Автосохранение** с дебаунсом 1с, с индикатором "сохранено/сохраняется". Не триггери автосохранение на каждый mousemove, только когда пользователь отпустил элемент (mouseup).

### 2.3. Быстрый режим (Quick Edit / Wizard)
Оставь wizard как точку входа по-умолчанию для НОВЫХ пользователей и для тарифа Free.
- Шаги: Имена молодожён → дата и время → место/адрес → фото обложки → цветовая схема → готово.
- Каждый шаг подставляет значение в соответствующий элемент ДЕФОЛТНОГО шаблона (предзаполненный канвас-документ wedding-luxury как старт).
- В конце пользователь видит готовое приглашение и две кнопки: "Опубликовать бесплатно" и "Настроить детали в редакторе" (последняя открывает продвинутый канвас-редактор).
- Нет перегрузки кнопками — один вопрос на экране, максимально просто. Это для мам/пап/заказчиков которые не хотят разбираться в редакторе.
- На тарифе Free быстрый режим доступен, продвинутый канвас — нет (показывает paywall "для полного контроля над дизайном — Стандарт/Премиум").

### 2.4. Визуальный редактор рассадки
Отдельный роут `/invitations/[id]/seating` (бэкенд/сущности стол/гость уже есть в БД, не дублируй):
- Пустой холст А4-ландшафт с сеткой и масштабом.
- Инструменты слева: "Круглый стол", "Прямоугольный стол", "Президиум", "Стена/перегородка", "Текст подпись", "Вход".
- Каждый стол: при добавлении появляется на холсте с дефолтной вместимостью (8 для круглого, 10 для прямоугольного). Можно таскать мышью, менять размер, вращать, менять номер/название, менять цвет, менять вместимость.
- Правая панель: список нерассаженных гостей с поиском. Гостя можно ПЕРЕТАЩИТЬ из списка прямо на стол (садится за стол, слот занимает, счётчик свободных мест уменьшается). Можно перетащить гостя со стола обратно или на другой стол.
- При клике на стол — всплывает список сидящих, можно удалить из стола крестиком.
- Сохранение автоматическое (как и в канвасе приглашения).
- Кнопка "Скачать PDF для тойханы" — генерируй PDF схемы с сервера (через @react-pdf/renderer или puppeteer на бэке).
- На мобильном показывай упрощённый список-версию (без холста), холст только на десктопе/планшете с мышью.
- Раньше рассадка была списком — теперь и список и канвас, переключение режимов.

### 2.5. Анимации
- Весь пак анимаций в отдельном CSS-файле, на @keyframes, общие классы `anim-fade`, `anim-fade-up`, и т.д. с CSS переменными для задержки/длительности.
- IntersectionObserver на гостевой странице: при скролле элемент попадает в вьюпорт на 20% — добавляется класс `is-visible` который триггерит анимацию.
- В редакторе анимации НЕ ПРОИГРЫВАЮТСЯ автоматически (мешают редактировать), вместо этого есть кнопка "просмотреть анимации" которая запускает их все с начала.
- По умолчанию у всех новых элементов анимация `fadeUp` с длительностью 0.6с и дефолтной задержкой.

### 2.6. Гостевая страница (`/i/[slug]`)
- **Никакого JS-оверхеда лишнего**: рендерится на сервере, на клиенте только IntersectionObserver для анимаций и интерактивные формы RSVP.
- Элементы позиционируются абсолютно точно как в редакторе, адаптивно под ширину экрана через проценты.
- Мобильная версия использует `mobile`-ветку документа если она есть, иначе — авто-перерасчёт на основе десктопа.
- Lighthouse perf >= 85 на мобильном, картинки через next/image с правильными размерами.
- Не показывай тулбары/контролы редактора — только чистый контент.

❌ Не используй jQuery, не используй DOM-манипуляции через document.getElement*, всё через React state/refs.
❌ Не храним секреты в клиентском коде.
❌ Не делай скругления/тени/анимации фиксированно в инлайн-стилях без возможности кастомизировать.

❌ Не ври что проверил если не запустил и не потыкал руками в редакторе.
