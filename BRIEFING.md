---

## 1. Что это

QazShaqyru — казахстанский SaaS цифровых приглашений на торжества: үйлену тойы,
ұзату, сүндет той, тұсаукесер, мерейтой, туған күн и прочее. Монорепо,
приложение одно: `apps/web` (Next.js 14 App Router, Prisma, Postgres).

Путь пользователя:

```
лендинг → /templates → /editor/<slug> → публикация → /invitations/<id> (хаб)
        → гости, персональные ссылки, RSVP, напоминания, рассадка
гость:  /i/<slug>?guest=<token>
```

Деньги: разовая оплата цены шаблона (`Template.priceKzt`, 2990–4990 ₸) снимает
водяной знак и открывает работу с гостями. Публикация при этом **бесплатна**.
Автоматического платёжного шлюза сегодня нет: `KASPI_MANUAL_PAY_LINK`
перекрывает всё, клиент платит по ссылке кассира и админ подтверждает руками.

Двуязычность ru/kz — суть продукта, **локаль по умолчанию казахская**. Локаль
интерфейса и локаль приглашения (`document.locale`) — разные вещи, их смешение
породило целый класс багов.

## 2. Владелец

Не разработчик. Код не читает и не будет. Судит по отрендеренной странице.
Переписка на русском, мат — обычный регистр речи, а не конфликт.

Что из этого следует на практике:

- **он поймает несоответствие.** Написать «исправлено», когда на экране не
  исправлено, дороже честного «не получилось»;
- **ему не нужен пересказ твоих действий**, нужен результат, число и то, что
  осталось сломанным;
- **его поправка — информация.** «Я просил не искать проблемы, а разделить
  категории» описывает дефект метода. Чинить метод, не оправдываться.

Полные требования цитатами — `HANDOFF.md` §1. Метод работы —
`WORKING-STANDARD.md`. Прочитать оба до первой правки.

## 5. Правила, которые нарушают чаще всего

1. **Ничто в кодовой базе не эталон.** Проект писался one-shot дешёвыми
   моделями. «Так уже сделано» — не аргумент. Крупные изменения приветствуются,
   косметика раздражает.
2. **Зелёные `tsc` и тесты не значат ничего.** Каждый найденный дефект их
   проходил. Смотреть на страницу в 390×844, залогиненным, в обеих локалях.
3. **Находка содержит число.** Пиксели, проценты, счётчики, строка 404.
4. **Самый частый дефект — код, который выглядит готовым, но никто его не
   зовёт.** Контрол, сохраняющий значение и не влияющий на страницу, — дефект,
   а не задел.
5. **Оценка без приукрас**, включая свою. Снятые собственные обвинения идут в
   отчёт наравне с находками.
6. **Продуктовые решения идут владельцу планом текстом**, а не правятся молча.

### Что запрещено в шаблонах

- тёмные шаблоны: «я давно говорил, что тёмное не делаем»;
- лица в кадре (люди — можно, лицо — нет);
- степь, юрты, кони, кумыс, ауыл;
- рисование ассетов кодом в SVG/CSS (настоящий растр резать и слоить — можно);
- выдуманный контент на гостевой странице.

## 6. Машина и инструменты

- **Дев-сервер поднимать preview-инструментом, не через Bash.**
- **Постгрес на 55432**, не 5432: Hyper-V занимает 5432, иначе каждая страница
  отдаёт 500.
- **Вход в дев** — телефон и пароль, регистрация на `/login` с любым `+7701…`.
  В скриптах логиниться через `POST /api/auth/login` и подставлять куку
  `session_token`: форма использует маскированный `tel`-инпут, `fill()` по ней
  не работает. Есть тестовый `+77015550142` / `Test12345`.
- **Долгие команды в фон.** `tsc` идёт 2–4 минуты, тесты 1–3, холодная
  компиляция маршрута до полутора минут.
- **Git Bash переписывает аргументы вида `/templates`** в путь Windows. Скрипты
  с маршрутами запускать из PowerShell.
- **Heredoc здесь съедает обратные слэши.** Скрипт с регулярками писать
  инструментом записи файла, а не `cat > file <<EOF`.
- **`ffmpeg` есть**: `C:\ffmpeg\bin\ffmpeg.exe`. Удобно раскладывать ролики на
  кадры и делать контактные листы.
- **Доступ к конкурентам.** API shaqyru24 живёт на `tyrasoft.kz` и с этой
  машины не резолвится. Рабочий путь один: toi.com.kz, загрузить
  `/assets/index-*.js`, выдрать имена чанков, скачать и грепать. 122 чанка,
  295 ассетов, минута из консоли браузера на их домене.

Полезное:

```bash
cd apps/web
node scripts/audit-routes.mjs --locale=kz --login=+77015550142 /dashboard
npx tsx scripts/prepare-template-assets.ts <slug>
npx tsx scripts/seed-templates.ts
npx tsx scripts/preview-invitation.ts <slug>
node scripts/shot-gate.mjs http://localhost:3000/i/preview-<slug> out.png
npx tsx scripts/self-check-template.ts <slug>
```

## 8. Ошибки, за которые уже заплачено

Полные списки в плейбуках; здесь те, что повторяются.

- **Отчитался раньше, чем проверил.** «Все восемь превью каталога сломаны» —
  сломаны были три, остальные не успели загрузиться за три секунды.
- **Замер по холодному маршруту.** Первый заход отдаёт скелет: ни заголовка, ни
  картинок. Целый набор ложных находок.
- **Свою правку в базе выдал за баг продукта.** Пометил заказ оплаченным
  напрямую, минуя код публикации, и записал последствие в дефекты.
- **Скопировал числа конкурента дословно.** Размеры и углы из разбора нельзя
  переносить как есть; отсюда пункт C14 в self-check.
- **Прочитал измерение как меню.** `visual-register.md` описывает у конкурентов
  два регистра, тёмный владельцем запрещён — и запрет нигде не был записан.
  Целый план шаблона в мусор.
- **Прочитал «нет предметов» как «голая стена».** Верх кадра в их роликах тихий,
  но не пустой: небо, цветение, золото по углам. Бриф с «пустой стеной» дал
  скучное видео.
- **Считал регистрозависимо.** Насчитал 17 вхождений ложной фразы о цене,
  реально их было 46 — искал только с заглавной буквы.
- **Добавил всё подряд в коммит.** В него попала выгрузка переписок с живыми
  ключами GCP, GitHub отклонил пуш. Смотреть, что стажится.
